## Projects

All three projects are built around the same dataset (**VideoGamesDB**), 
showcasing how a data analyst can take a single business problem from 
database design all the way to a published dashboard.

### 🗄️ 1. Database Design (SQL)
Relational schema design for a video games catalog. Tables, keys, 
relationships, and analytical queries built in SQL Server.

➡️ [View project](./database-project)

---

### 🐍 2. Python / Jupyter Analysis
Exploratory data analysis on the same database using Python, Pandas, 
and Seaborn. Connects directly to SQL Server via SQLAlchemy and produces 
clear visualizations of trends in the games industry.

➡️ [View project](./jupyter-project)

---

### 📊 3. Power BI Dashboard
Interactive 5-page Power BI dashboard analyzing the video games catalog: 
home, catalog overview, developer analysis, pricing, and quality trends. 
Includes screenshots for instant preview.

➡️ [View project](./powerbi-project)
